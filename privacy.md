# Fotstats Privacy Policy

Last updated: August 24, 2026

Fotstats is a browser extension that displays additional match statistics
on FotMob match pages.

## Data collection

Fotstats does not collect, transmit, sell, or share any user data.

The extension does not use analytics, tracking, advertising, or any
third-party data service. No data is sent to the developer or to any
server operated by the developer.

## Local data

Fotstats stores user preferences (such as which statistics are shown)
locally in the browser using the Chrome storage API. This data remains
on the user's device, is not transmitted anywhere, and is removed when
the extension is uninstalled.

## Page access

The extension runs only on fotmob.com. It reads match information from
the page in order to calculate and display statistics within the page
itself. This information is processed locally and is not stored or
transmitted.
